# Compliance and fiscal

No legal/tax rule is hard-coded as an allow. Resolver requires a dated active profile matching Company/FOP and action. VAT mode remains blocked unless the dedicated adapter and acceptance suite are enabled.

PRRO receives actual goods and immutable payment snapshots. Gift Certificate is an internal payment kind; fiscal name/code/form come from the approved mapping. Corrective returns use original snapshots even if a profile was later revoked.
