# Gap analysis

Стандартний Coupon Code не має балансу, liability, reservation та return provenance; Customer advance не підтримує bearer/multi-location funding. Тому джерелом істини є власний certificate ledger.

Реалізовано P0 core: settings/network/program/profiles, secure issue/batch, POS sale/redemption/mixed payment, item allocation, full/partial repeated returns, replacement, expiry, same/cross-entity settlement rows, GL/fiscal/loyalty adapters, reconciliation й protected print.

Окремі gates: VAT first/second event, Deferred Discount, ecommerce, public balance, автоматичні inter-company settlement JE, digital delivery та high-volume import залишаються disabled до окремих acceptance suites.
