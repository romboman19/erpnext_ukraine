# Cashier guide

For sale, open an empty cart, choose “Продати сертифікат”, set Program/nominal/holder, accept ordinary money, then print the receipt/certificate once. Never photograph or copy a token into notes.

For redemption, scan the certificate, confirm the quoted amount, take only the displayed top-up and finish checkout. Never give cash change from a certificate.

For return, scan the original receipt barcode and select returned quantities. The system restores the original certificate share; pay only the displayed cash/card refund.
