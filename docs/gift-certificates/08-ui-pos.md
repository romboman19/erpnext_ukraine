# POS-UA flow

Cashier can sell a certificate only in an empty dedicated cart. Merchandise cannot be mixed with issued certificates. Redemption is scanned before checkout; the modal shows eligible total, amount and masked balance. Server inserts the Gift Certificate payment rows and calculates the cash/card top-up.

Return starts from the unique receipt barcode. The refund modal pays only the original money component; certificate funding is restored automatically to its lineage target.
