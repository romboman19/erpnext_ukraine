# ADR-0001: окремий Frappe-застосунок

- Статус: Accepted
- Дата: 2026-07-13

## Контекст

Комісійна та консигнаційна торгівля охоплює склад, власність партій,
ціноутворення, розподіл продажів, партнерські зобов'язання, платежі, повернення,
аудит та звірку. Це окремий бізнес-домен, а не локалізація і не зовнішній
інтеграційний провайдер.

Наявні застосунки мають інші межі:

- `erpnext_ua` володіє українською локалізацією, FOP Profile, POS і ПРРО;
- `ukrainian_integrations` володіє зовнішніми інтеграціями;
- ERPNext залишається джерелом істини для стандартних складських та
  бухгалтерських документів.

## Рішення

Розробляти функціональність у самостійному репозиторії та Frappe app
`erpnext_consignment_and_commission`.

- `required_apps = ["erpnext"]`;
- інтеграції виконуються через versioned API, adapter protocols і feature
  detection;
- доменні модулі не імпортують `erpnext_ua` або `ukrainian_integrations`;
- застосунок працює без POS Order через контрольований Sales Invoice fallback;
- модифікація Frappe/ERPNext core заборонена.

## Наслідки

Переваги:

- незалежне встановлення, тестування і версіювання;
- відсутність примусової залежності локалізації від торгової моделі;
- можливість використання на generic ERPNext site;
- чітке володіння даними та міграціями.

Вартість рішення:

- потрібні стабільні cross-app контракти;
- інтеграційні тести мають перевіряти різні комбінації встановлених apps;
- події Sales Invoice не можуть залежати від порядку hooks між apps.
