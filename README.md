# ERPNext Ukrainian Integrations

Єдина ERPNext/Frappe app для українських інтеграцій:
- UA Shipment (Нова Пошта, Укрпошта, інші)
- PBX + SMS (VitalPBX, TurboSMS)
- Payments UA (LiqPay, Monobank, Privat POS)
- Ecommerce UA (маркетплейси та власні сайти)

## Status
Bootstrap repository created. Architecture and modules will be migrated in phases.
